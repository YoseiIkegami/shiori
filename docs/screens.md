# 画面一覧

フロントは SPA（Vue Router）。全 trip で同一ビルドを共有する。

## ルート

| パス | 画面 | 説明 |
|---|---|---|
| `/` | ホーム | LP。写真スタック・コピー・価格・CTA |
| `/create` | 旅の作成 | 2 ステップ（なまえ → 設定 → 決済） |
| `/create/success` | 発行完了 | 決済後。共有中心・QR・幹事 URL |
| `/manage/:slug` | 幹事設定 | `?token=` 必須。状況・共有・設定・終了 |
| `/t/:tripId` | 旅本体 | 撮影フロー or 解禁後ボード（`slug` または UUID） |

## ホーム `/`

- 写真スタックのヒーロー（CSS。実写差し替え可）
- コピー + CTA のみ
- プラン: `フィルム50枚・7日保存 ¥150`

## 旅の作成 `/create`

2ステップ構成。

### 1 / 2 — 旅のなまえ

- プレースホルダー `例: natsu-ibuki` + 右端 **提案**
- フォーカス時のみルール: `英数字とハイフンで 3〜30文字`
- 状態（入力時のみ）: `✓ この名前は使えます` / `名前を確認中…` / 形式・重複エラー
- 重複: `この名前はすでに使われています`
- 主CTA: **次へ**（無効時は `名前を入力して次へ` など）
- 注記: `あとから表示名は変更できます`

### 2 / 2 — 旅の設定

- 見出し「旅の設定」+「おすすめのままではじめられます」
- フィルム・終了時刻・ひとこと・日付表示に（おすすめ）表記
- ニックネーム（準備中）は非表示
- 主CTA: **¥150 で旅をはじめる**

## 発行完了 `/create/success`

- 主CTA: **リンクを送る**
- 補助: リンクをコピー、QR（折りたたみ）
- 幹事リンク: **設定を開く**（折りたたみ）+「設定リンクはメールにも送信予定です」
- 撮影へは最下部のテキストリンク

## 幹事設定 `/manage/:slug?token=...`

4ブロック構成。

1. **状況** — 枚数 + 進捗バー + 共有する
2. **共有** — 短縮 URL（`…/t/{slug}`）・コピー（完全 URL）・QR
3. **旅の設定** — フォーム + 保存
4. **危険な操作** — 旅を終了して写真を開く

## 旅本体 `/t/{slug}`

`is_revealed` と支払い状態で表示が切り替わる。詳細は [撮影・解禁フロー](./camera-flow.md)。

| 条件 | 表示 |
|---|---|
| trip なし | エラー |
| `payment_status !== 'paid'` | この旅はまだ公開準備中です |
| 未解禁 | 撮影フロー |
| 解禁済み | 封筒演出 → 写真の山 |

`/t/test` のみ、検証用「開始前／開始後」トグルあり（本番公開前に除去予定）。
