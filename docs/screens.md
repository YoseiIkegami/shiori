# 画面一覧

フロントは SPA（Vue Router）。全 trip で同一ビルドを共有する。

## ルート

| パス | 画面 | 説明 |
|---|---|---|
| `/` | ホーム | LP。写真スタック・コピー・価格・CTA |
| `/create` | 旅の作成 | 2 ステップ（なまえ → 設定 → 決済） |
| `/create/success` | 発行完了 | 決済後。共有中心・QR・幹事 URL |
| `/manage/:slug` | 設定 | `?token=` 必須。状況・共有・共有言語・メール・終了 |
| `/terms` `/privacy` `/legal` | 法務 | 下書き（事業者情報は公開前に確定） |
| `/t/:tripId` | 旅本体 | 撮影フロー or 解禁後ボード（`slug` または UUID） |

## ホーム `/`

- 写真スタックのヒーロー（CSS。実写差し替え可）
- コピー + CTA のみ
- プラン: `フィルム50枚・7日保存 ¥150`

## 旅の作成 `/create`

2ステップ構成。

### 1 / 2 — 旅のなまえ

- 自由入力（言語・文字種の制限なし、最大60文字）+ 右端 **提案**
- 重複チェックなし（表示名はユニーク不要）
- 主CTA: **次へ**

### 2 / 2 — プラン

- 選んだ表示名を上部に表示
- プラン・フィルム枚数
- 主CTA: **無料ではじめる** / **¥…を支払う**

## 発行完了 `/create/success`

- 主CTA: **リンクを送る**
- 補助: リンクをコピー、QR（折りたたみ）
- 幹事リンク: **設定を開く**（折りたたみ）+「設定リンクはメールにも送信予定です」
- 撮影へは最下部のテキストリンク

## 幹事設定 `/manage/:slug?token=...`

4ブロック構成。

1. **状況** — 枚数 + 進捗バー + 共有する
2. **共有** — 短縮 URL（`…/t/{share_token}`）・コピー（完全 URL）・QR
3. **旅の設定** — 表示名・メール（確認メール再送信）・トグル + 保存
4. **危険な操作** — 旅を終了して写真を開く

## 旅本体 `/t/{share_token}`

`is_revealed` と支払い状態で表示が切り替わる。詳細は [撮影・解禁フロー](./camera-flow.md)。

| 条件 | 表示 |
|---|---|
| trip なし | エラー |
| `payment_status !== 'paid'` | この旅はまだ公開準備中です |
| 未解禁 | 撮影フロー |
| 解禁済み | 封筒演出 → 写真の山 |

互換のため旧 `/t/{slug}` も解決する。検証用は `/t/test`（`share_token='test'`）。
