# 多言語（i18n）

## 方針

- ライブラリ: **vue-i18n**（`legacy: false` / Composition API）
- 原文・フォールバック: **ja**
- 初期対応: **ja / en**
- URL にロケールは載せない（SPA）

## 検出順

1. `localStorage['shiori.locale.v2']`（対応ロケールのみ採用）
2. 未設定なら **`ja`**（ブラウザ言語は見ない。英語はスイッチャーで明示選択）
3. 旧キー `shiori.locale` は破棄（ブラウザ自動判定の名残を消す）

`setLocale()` で永続化・`html[lang]`・Vant Locale を同期。
ホームの言語スイッチャーは `SUPPORTED_LOCALES` × `LOCALE_LABELS` から自動生成。

## ファイル

| パス | 内容 |
|---|---|
| [`src/i18n/index.ts`](../src/i18n/index.ts) | createI18n / detect / setLocale / currency |
| [`src/locales/ja.json`](../src/locales/ja.json) | 日本語 |
| [`src/locales/en.json`](../src/locales/en.json) | 英語 |

キーは二階層（例: `home.headline`, `plan.standard.summary`）。

## 通貨

| locale | Stripe currency | 表示 |
|---|---|---|
| ja | jpy | `numberFormats`（JPY） |
| en（その他） | usd | `numberFormats`（USD） |

金額本体は Edge Function のプランマスタが決定する。

## 言語追加手順

1. `src/locales/{code}.json` を追加（ja をコピーして翻訳）
2. `SUPPORTED_LOCALES` と `LOCALE_LABELS`、`messages` に登録
3. `numberFormats` と Vant Locale を追加
4. 通貨が JPY/USD 以外なら Checkout / プランマスタも拡張
5. **表示名の提案語彙**を各 `src/locales/{code}.json` の `nameSuggest.prefixes` / `suffixes` / `adjectives` に追加。プレースホルダ `create.namePlaceholder` も合わせる

表示名は言語自由。[`nameGenerator.ts`](../src/lib/nameGenerator.ts) が提案候補を組み立てる。内部 `slug` はサーバ発行。

## 翻訳範囲（現状）

全 UI 文言をキー化済み（ホーム・作成・撮影〜確認・ボード・幹事・発行完了・404・エラー/トースト含む）。
法務ページ（利用規約・プライバシー・特商法）は法的文書のため ja のみ（意図的）。

## ヘッドライン多言語展開（採用・`home.headline`）
