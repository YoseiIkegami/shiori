# 多言語（i18n）

## 方針

- ライブラリ: **vue-i18n**（`legacy: false` / Composition API）
- 原文・フォールバック: **ja**
- 初期対応: **ja / en**
- URL にロケールは載せない（SPA）

## 検出順

1. `localStorage['shiori.locale']`
2. `navigator.language` が `ja*` → `ja`、それ以外 → `en`

`setLocale()` で永続化・`html[lang]`・Vant Locale を同期。

## ファイル

| パス | 内容 |
|---|---|
| [`src/i18n/index.ts`](../src/i18n/index.ts) | createI18n / detect / setLocale / currency |
| [`src/locales/ja.json`](../src/locales/ja.json) | 日本語 |
| [`src/locales/en.json`](../src/locales/en.json) | 英語 |

キーは二階層（例: `home.headline`, `plan.standard.summary`）。

## 通貨

| locale | Stripe currency | 表示 |
|---|---|---|
| ja | jpy | `numberFormats`（JPY） |
| en（その他） | usd | `numberFormats`（USD） |

金額本体は Edge Function のプランマスタが決定する。

## 言語追加手順

1. `src/locales/{code}.json` を追加（ja をコピーして翻訳）
2. `SUPPORTED_LOCALES` と `messages` に登録
3. `numberFormats` と Vant Locale を追加
4. 通貨が JPY/USD 以外なら Checkout / プランマスタも拡張

## 翻訳範囲（現状）

ホーム・作成・プラン文言をキー化。旅本体（カメラ等）は次フェーズ。
