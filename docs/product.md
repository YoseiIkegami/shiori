# プロダクト概要

## コンセプト

リンクを踏むだけでカメラが起動し、写真とひとことを投稿できる。  
枚数上限に達するか、幹事が設定した終了時刻になるまで内容は非公開。  
解禁後は同じ URL で、真上から見たポラロイドの山を一斉に閲覧できる。

キャッチコピー: **届くまで、開かない写真。**

## 誰が何をするか

| 役割 | やること |
|---|---|
| 幹事 | `/create` で旅を発行（Stripe 決済）→ 共有リンクを配布 → `/manage` で設定・手動終了 |
| 参加者 | `/t/{slug}` で撮影・投稿（ログイン不要） |
| 全員 | 解禁後、同じ URL でボード閲覧・個別保存 |

## 解禁条件（現行）

次のいずれかで `is_revealed = true` になる。

1. **枚数**: `photos_count >= max_photos`（DB トリガーで確定）
2. **時刻**: `reveal_at` が設定され、現在時刻を過ぎた（取得時に lazy promote）
3. **手動**: 幹事が幹事設定から「旅を終了する（解禁）」

枚数と時刻は **どちらか先に達した方** で終了する。
