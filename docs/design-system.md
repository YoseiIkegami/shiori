# デザインシステム

## 方針

「静かな旅の写真箱」。白い面・細い罫線・余白を基本とし、1画面につき色付きの主CTAは原則1つ。

- **1画面フィット**: iPhone XR（414×896）および iPhone 12 / 12 Pro（390×844）相当で、ページ縦スクロールなしに収める（正本ルール: [`.cursor/rules/fit-viewport.mdc`](../.cursor/rules/fit-viewport.mdc)）
- 本編（カメラ・ボード）は没入型の固定レイアウトを維持
- サービス周辺もスクロール前提にしない。溢れる場合は余白・型サイズ・挿絵を縮める
- ノスタルジーは写真と紙だけ。操作UIに強い立体感は持ち込まない

例外として縦スクロールを許すのは、法務の長文ページと、写真枚数が不定のボード一覧のみ。

## イラスト

感情ピークのサービス周辺画面だけに、フラットな挿絵で期待感を足す。説明文は増やさない。

| 項目 | 方針 |
|---|---|
| 置いてよい | ホームHowto、404、発行完了、将来の感情ピークのみ |
| 置かない | カメラ／プレビュー／ボード本編／幹事設定の作業UI |
| 形式 | **SVG風の見た目**でよい。インラインSVGでも、WebP/PNG（`public/`）でも可。発行完了は表示幅おおよそ 200〜240px |
| トーン | フラット・線少なめ・面塗り。写真風・3D・リアル実写は使わない。色は `--surface` `#F8F7F4` / paper `#FFFAF0` / `#d8cfc2` / `--accent` `#BD5825` / ink `#3D3026` 系 |
| 動き | 任意。ラスタは静止画で十分なことが多い。アニメする場合は `prefers-reduced-motion: reduce` で止める |
| コピー | イラスト用の説明文は足さない。装飾は `aria-hidden` |
| 資産 | 生成・自作可。undraw 等の外部キットは参考のみ（同梱しない） |

発行完了の構図: つば広帽子の女性が地平線を遠望し、首ストラップのカメラが副次的に見える。横顔で顔は読める。背景は空＋地平線。ポラロイド枠は使わない。

ホームHowto（3枚）: 人物シリーズではなく道具で語る。①カメラで撮る（女性なし）②封筒に写真を入れる ③並べて見られる。画風・色は発行完了と揃える。
