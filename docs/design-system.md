# デザインシステム

## 方針

「静かな旅の写真箱」。白い面・細い罫線・余白を基本とし、1画面につき色付きの主CTAは原則1つ。

- 本編（カメラ・ボード）は没入型の固定レイアウトを維持
- サービス周辺はネイティブスクロール（`.flow-shell`）
- ノスタルジーは写真と紙だけ。操作UIに強い立体感は持ち込まない

## カラー・サーフェス

| トークン | 値 | 用途 |
|---|---|---|
| `--surface` | `#F8F7F4` | ページ背景 |
| `--line` | `#E6E2DA` | 罫線 |
| `--paper-cream` | `#FFFAF0` | 紙面アクセント |
| `--ink-brown` | `#3D3026` | 見出し |
| `--accent` | `#D96F34` | 主CTA・小さな強調 |
| `--text` | `#2E3437` | 本文 |
| `--text-muted` | `#71777A` | 補足 |

## レイアウト

| クラス | 用途 |
|---|---|
| `.flow-page` | 暖色背景のサービス画面 |
| `.flow-shell` | 最大幅420px・ネイティブスクロール |
| `.flow-divider` | セクション区切り |
| `.flow-input` | 白地 + 1px 罫線の入力 |
| `.flow-btn.primary` | 唯一の主CTA（min-height 54px） |
| `.flow-text-btn` | テキストリンク風の補助操作 |

## 文言（作成・slug）

| 状態 | 文言 |
|---|---|
| 成功 | ✓ この名前は使えます |
| 確認中 | 名前を確認中… |
| 形式不正 / 予約語 | 英数字とハイフンで 3〜30文字 |
| 重複 | この名前はすでに使われています |

角丸: 8 / 10 / 12px。影は `--shadow-raised-sm` のみ（浮かせる対象限定）。

## 画面ごとの主CTA

| 画面 | 主CTA |
|---|---|
| ホーム | 旅をはじめる |
| 作成 1/2 | 次へ |
| 作成 2/2 | ¥{価格} で旅をはじめる |
| 発行完了 | リンクを送る |
| 幹事設定 | 共有する（状況行）/ 保存（設定ブロック） |
