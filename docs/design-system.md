# デザインシステム

## 方針

「静かな旅の写真箱」。白い面・細い罫線・余白を基本とし、1画面につき色付きの主CTAは原則1つ。

- 本編（カメラ・ボード）は没入型の固定レイアウトを維持
- サービス周辺はネイティブスクロール（`.flow-shell`）
- ノスタルジーは写真と紙だけ。操作UIに強い立体感は持ち込まない

## カラー・サーフェス

| トークン | 値 | 用途 |
|---|---|---|
| `--surface` | `#F8F7F4` | ページ背景 |
| `--line` | `#E6E2DA` | 罫線 |
| `--paper-cream` | `#FFFAF0` | 紙面アクセント |
| `--ink-brown` | `#3D3026` | 見出し |
| `--accent` | `#BD5825` | 主CTA・小さな強調（白文字で AA 相当） |
| `--accent-pressed` | `#9E4A1F` | 主CTA 押下 |
| `--text` | `#2E3437` | 本文 |
| `--text-muted` | `#63696C` | 補足 |

## 影

| トークン | 用途 |
|---|---|
| `--shadow-raised-sm` | 浮かせる対象（限定） |
| `--shadow-raised-md` / `--shadow-raised-lg` | ダイアログ等 |
| `--shadow-inset` / `--shadow-inset-deep` | 押下・入力欄の凹み |

## レイアウト

| クラス | 用途 |
|---|---|
| `.flow-page` | 暖色背景のサービス画面 |
| `.flow-shell` | 最大幅420px・ネイティブスクロール |
| `.flow-divider` | セクション区切り |
| `.flow-input` | 白地 + 1px 罫線の入力 |
| `.flow-btn.primary` | 唯一の主CTA（min-height 54px） |
| `.flow-text-btn` | テキストリンク風の補助操作 |

## 文言（作成・slug）

| 状態 | 文言 |
|---|---|
| 成功 | ✓ この名前は使えます |
| 確認中 | 名前を確認中… |
| 形式不正 / 予約語 | 英数字とハイフンで 3〜30文字 |
| 重複 | この名前はすでに使われています |

角丸: 8 / 10 / 12px。

## 画面ごとの主CTA

| 画面 | 主CTA |
|---|---|
| ホーム | 旅をはじめる |
| 作成 1/2 | 次へ |
| 作成 2/2 | ¥{価格} で旅をはじめる |
| 発行完了 | リンクを送る |
| 幹事設定 | 保存（共有は枠線ボタン） |

## フォント

すべて Google Fonts 経由の **OFL**（商用の Web 埋め込み可）。

| 用途 | フォント | 備考 |
|---|---|---|
| 本文・UI | BIZ UDPGothic | 森沢 UD。画面の読みやすさ |
| ブランド・見出し | Shippori Mincho | しおり／記憶の雰囲気 |
| ポラロイド手書き | Klee One | ユーザー入力のキャプション・ニックネームのみ（プレースホルダ・システム見出しには使わない） |
| 日付スタンプ（合成） | DSEG7 Classic Italic | LED 風 |

CSS 変数: `--font-ui` / `--font-display` / `--font-hand`
